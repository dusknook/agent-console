你的通道是**复制粘贴**，不是 URL。做法：把下面 6 条消息**按序号依次**发出去，
发完再让它开工。

**顺序不能乱，也不要跳片。** 6 片是同一份文档按序切开的，
拼起来**逐字节等于** `豆包开测版.md`（46234 字节 / 1049 行）——

## 两条路，选一条

- **对方支持长文本** → 直接贴 `00_全量单条.md`（45.2 KB，与 `豆包开测版.md` 同字节），一条搞定。
- **对方单条有长度上限 / 会被截断** → 用上面 6 片，逐条贴。

## 怎么知道没贴漏

每片开头有一行 `【正文行 X–Y，共 1049 行…】`。
贴完 6 片后，可以让对方**回读每片的行号范围**：
接起来应当是 `1–1049` 连续且无缺口（生成时 S8 已机器校验过连续性）。

## 生成方式（可复现）

```
node tools/make-doubao-paste.mjs
```

切点是**自动选的**（按 `## ` → `### ` → 任意空行 三级优先，在 ≤ 13KB 的前提下尽量装满），
不是手写行号 —— 手写行号任何一次正文增删都会失效。
生成器带 9 组自检（拼回恒等、行数守恒、每片体积、代码围栏成对、切点落空行、关键锚点在场、
无空片、片头行号连续、全量同字节），任一不过就 **exit 1 且不写出任何文件**。
